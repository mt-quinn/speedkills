# Crew portraits

Icons by **Delapouite** (https://delapouite.com/) and **Lorc** (https://lorcblog.blogspot.com/), from [game-icons.net](https://game-icons.net/), licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

The full-canvas black background path has been removed for transparent silhouettes. The viewer applies color with CSS masks; no species-specific gameplay effects are implied. Each named crew member has a stable, unique portrait assignment in `manifest.json`, including the artist and original icon page.
